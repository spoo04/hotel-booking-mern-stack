# hotel-booking-mern-stack
ull-stack hotel booking system built with MongoDB, Express.js, React.js &amp; Node.js. Features: hotel search/filter, real-time availability, secure bookings with Stripe, user auth (JWT), admin dashboard, responsive UI (Tailwind). Deployed on Vercel/Render. Perfect portfolio project showcasing CRUD, auth, payments &amp; modern React patterns.
